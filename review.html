1. Requested Scopes & Business Justification

Zaitoon Studio requests only the minimal set of scopes strictly required to deliver a transparent, creator-controlled publishing experience:

user.info.basic

Creator Identity Awareness

Used exclusively to display the creator's verified display nickname, username handle, and avatar in the Creator Review Studio header. In accordance with TikTok UX guidelines, this ensures the creator has full awareness of which specific TikTok account will receive the upload before initiating transfer.

video.publish

Direct Post Capabilities & Initialization

Enables the application to query /v2/post/publish/creator_info/query/ to fetch available privacy options, interaction permissions (comments, Duet, Stitch), and max post duration. Following explicit creator review and consent, initiates the publishing session via /v2/post/publish/video/init/ and monitors processing status via /publish/status/fetch/.

video.upload

Client-Side Media Chunk Transfer

Authorizes uploading binary video chunks from the creator's local device to the presigned upload URL provided by TikTok during the Direct Post initialization step (using the official FILE_UPLOAD method).

2. Step-by-Step Creator-in-the-Loop Workflow

Zaitoon Studio does not perform unrestricted or unattended headless TikTok publishing. Every publication strictly follows this 9-step progression:

1

Creator Opens Review Workflow

The creator launches the local Creator Review Studio interface on their workstation to inspect rendered short-form video artifacts ready in the local queue.

2

Creator Sees Account & Identity Information

The studio authenticates via Login Kit and queries creator_info/query/. The creator's nickname, verified username, avatar, and max duration privilege are prominently displayed.

3

Creator Previews Content

The creator plays the full vertical video locally in an HTML5 player, verifying video audio, pacing, visuals, and subtitle timing.

4

Creator Edits Caption & Hashtags

The creator enters and reviews the post title and hashtags. A real-time character counter enforces the 2,200 character ceiling using exact UTF-16 code units.

5

Creator Selects Privacy Level

The dropdown is populated dynamically from creator_info.privacy_level_options. In compliance with TikTok guidelines, there is no default value; the creator must manually choose.

6

Creator Controls Relevant Interaction Settings

Toggles for Comments, Duet, and Stitch are unchecked by default. If the creator's TikTok privacy settings prohibit an interaction, the toggle is automatically disabled and greyed out.

7

Creator Discloses Content Details

Commercial Content Disclosure is OFF by default. If enabled, creators declare Brand Organic or Branded Content (which cannot be private). AIGC labeling is truthfully toggled based on channel type.

8

Creator Gives Explicit Approval

The "Publish to TikTok" button remains completely disabled until the creator explicitly checks the mandatory Music Usage Confirmation statement.

9

Publish & Status Tracking

Upon creator click, the video is transferred via FILE_UPLOAD and real-time status is polled via /publish/status/fetch/ until processing completes.

Key UX Safeguards Implemented:

  • Dynamic Privacy Selection: Dropdown options are populated live from creator_info.privacy_level_options. No default value is selected; manual selection is required.
  • Interaction Flags: Duet, Stitch, and Comments are unchecked by default. If the creator's TikTok privacy settings prohibit an interaction, the toggle is greyed out with an explanatory notice.
  • Commercial Content Disclosure: Turned OFF by default. If enabled, creators must select Brand Organic or Branded Content. Branded Content visibility is strictly prevented from being set to Private (SELF_ONLY).
  • UTF-16 Character Limit: Real-time rune counter enforces the 2,200 character boundary using exact UTF-16 code units (accurately accounting for emoji surrogate pairs and Bengali conjuncts).
  • Explicit User Consent: The Publish button is disabled by default. It activates only after the creator confirms the mandatory Music Usage Confirmation statement.
